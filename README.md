# AlternativeReality

An homage to some of the best games since the 1980s—from The Legend of Zelda and Fallout to Who Framed Roger Rabbit, Syndicate, Teenage Mutant Ninja Turtles, and beyond. A strange, playful world of exploration, role-playing, tactical chaos, and unexpected adventures, with its own personality and sense of humor.

A renderer-neutral, self-hosted multiplayer world derived from real geography. One authoritative reality server drives every client: the current browser-based top-down client and, later, a browser-based WebGL 3D client.

The playable vertical slice imports OpenStreetMap geography around downtown Vancouver, Washington as reference data; it never displays a real map. New 2 km geographic cells generate and cache locally as the camera or player explores beyond the loaded area. It builds a stylized angled tile world with roads, sidewalks, textured terrain, complete buildings, vegetation, wildlife, NPCs, vehicles, weather, dungeons, private bases, and players. The authoritative server owns accounts, inventory, movement, combat, trade, health, hydration, stamina, hourly weather, multiplayer synchronization, and SQLite persistence. Normal object modification remains disabled during this exploration milestone.

## Chosen stack

- **Server and canonical model:** C# / .NET 8 and ASP.NET Core. It is cross-platform, fast, easy to debug and publish as a native service, and exposes a renderer-neutral protocol.
- **Browser clients:** dependency-free HTML Canvas and JavaScript for 2D now, with WebGL through an open-source library such as Babylon.js for the later 3D view. Browsers are not limited to tile graphics; the current client already renders projected vector roads and footprints.
- **Shared contract:** canonical C# records define server state, while the versioned JSON protocol is the client boundary. TypeScript definitions can be generated from that contract as the browser client grows.
- **Networking:** JSON over WebSockets for the prototype. Messages describe logical actions and entities. Binary serialization can be added after profiling without changing simulation semantics.
- **Persistence:** SQLite in WAL mode. Only characters and reality deltas are saved; untouched geographic features regenerate from cache and seed.
- **Geography:** OpenStreetMap/Overpass plus a rough SRTM90m elevation grid through OpenTopoData, converted once into a final canonical world-block cache behind provider interfaces.

See [Architecture](docs/ARCHITECTURE.md), [Protocol](docs/PROTOCOL.md), and [database schema](docs/DATABASE.md) for the concrete design.

## Run locally

Requires the .NET 8 SDK. The first run needs internet access to populate the geographic cache; subsequent runs use the cache.

```powershell
dotnet run --project src/AlternateEarth.Server
```

Open [http://localhost:5080](http://localhost:5080). On a completely new server, the first-start screen offers browser location and falls back to manually entered latitude/longitude; this chooses the geography for the reality and is saved locally under `data/`. It is separate from player positioning. A first-time browser then asks for a unique 3–10 character username and password and stores an opaque server-issued session in an HTTP-only cookie. Returning players use the same credentials on a new device.

Area generation and map-window preparation run outside each player's command queue, so loading a neighboring area does not hold up pings or commands in the loaded world. NPC wandering routes use up to two background CPU workers with cancellation deadlines; the simulation applies completed routes only if the actor and navigation map still match. The God Mode Performance panel shows actor/transit tick durations, ping latency, route worker count, and the most expensive measured rendering stage. Hover the map timing row for command/job peaks and counts over 100 ms; `/api/diagnostics` exposes the same aggregate timings to authenticated God Mode players.

The browser reuses a buffered ground image for grass, terrain, roads, and sidewalks while the camera scrolls. Map, elevation, zoom, projection, and viewport changes invalidate the image. Bus stops have benches: click the sign or bench, then wait within three meters to sit down. Boarding, cancelling the wait, or displacement ends the seated pose.

Bus-stop locations are at least about 400 meters apart, with paired stops across two-way roads. Long corridors retain mile spacing. Buses leave a gap in traffic and yield instead of damaging each other; a mutually blocked bus can slowly reverse along its recent safe path to make room, stopping if a person or obstacle is behind it. Ground movement checks the entire movement segment against live bus footprints, including in God Mode; UFOs can fly over buses. High-density displays adapt canvas resolution after sustained slow rendering while keeping interface text at native resolution.

For access from other devices on the same network, run `tools/open-lan-port.ps1` once from an Administrator PowerShell. It creates an inbound TCP 5080 rule restricted to `LocalSubnet`. Other devices can then open `http://<server-lan-ip>:5080`.

Hovering a building shows its available address. Driveways avoid buildings, water, fences, and mapped obstacles; generated vegetation, cars, and lights leave them clear. Existing canonical caches are loaded unchanged. Parcel boundaries become stylized fences with open gates on at least two sides. Geographic food, gas, furniture, weapon, vehicle, clothing, hardware, sporting-goods, and convenience businesses create color-coded storefronts and roof flags naming what they sell. Hardware and sporting-goods merchants carry randomized weapons/bikes; vehicle dealers carry dirt bikes and motorcycles. Moving any edge of the viewport into a new geographic cell activates it before the player enters it, shades that exact area, and draws a pulsing boundary with repeated **LOADING MAP** signs and elapsed time. The server prepares adjacent blocks in the background—cardinal blocks first at login, then side/forward/diagonal blocks in the direction of travel—without activating or sending those blocks to the client. A persistent task banner distinguishes blocking loading, generation, routing, and client rendering work. The God Mode-only Performance panel shows FPS, render time, visible/loaded objects, network traffic, server memory, active map preparation, and load time. New terrain arrives under near-opaque fog with faint block lines; merchants sell a $1–$1,000 map that permanently reveals the current block for that player and is never offered there again. Snapshots identify exact loaded cells, so diagonal exploration cannot clear fog over an ungenerated hole inside the world's aggregate bounds. Final generated canonical map blocks stay local to each reality server under `data/world-cache/` and are never committed. New source responses are held only in memory; an old provider cache, if found for a block, is consumed once and removed. Once a canonical block exists, the game engine reads it directly and does not revisit the source dataset.

Buildings cost at least $350,000, with the authoritative normal price growing exponentially from the footprint's estimated square footage. That normal price is always displayed. God Mode bypasses affordability and wallet deduction without changing the quoted price.

Food, convenience, and gas merchants may stock energy drinks for a randomized $2–$10. Consuming one doubles final movement speed and raises carrying capacity from 50 to 100 pounds for 15 minutes, during which the character cannot sleep. A five-minute crash follows at one-fifth speed and 10-pound capacity; sleeping after the boost ends removes the crash immediately. The HUD shows the live phase and countdown, and the server persists both deadlines across reconnects and restarts.

The reality configuration—including center, size, name, seed, and player limit—is in `src/AlternateEarth.Server/appsettings.json`. Runtime state is written under `data/` and is intentionally not committed.

## Geographic attribution

Map features are © OpenStreetMap contributors and used under the [Open Database License](https://www.openstreetmap.org/copyright). Elevation is requested from an OpenTopoData SRTM90m endpoint and cached locally.

Current temperature, precipitation, and conditions are supplied by [Open-Meteo](https://open-meteo.com/) and refreshed by the reality server hourly. The client derives sunlight from sunrise/sunset, shows the current moon phase, brightens full-moon nights, and gives the player a small local light in darkness.

The server also tracks a persistent 0–100 body-heat meter. Standing still below 50 °F loses warmth; suitable movement and insulated hats, shirts, sweaters, jackets, and warming pants reduce that loss. Moving above 80 °F raises body heat; cooling hats, shirts, and shorts reduce heat gain and improve cooling. Reaching zero warmth slowly removes hearts, while overheating rapidly drains stamina. Indoor areas recover toward a comfortable temperature, and God Mode remains climate-protected.

God Mode testing: right-click open outdoor ground, then choose **Place NPC here**, **Place fake player here**, or **Place animal here** (a deer). Targets stay put until combat moves them. Fake players use player combat and obey PvP settings, without creating saved accounts. **Clear my test characters** removes your targets; up to 30 may be placed at once, and they disappear when the server restarts.

The UFO Probulator switches on/off by clicking your UFO. Its downward cone extends about 15% beyond the ground shadow (default horizontal radius 1.7 meters). Hit detection covers the entire flight path between simulation ticks, including turns, at half its previous speed (150 mph by default, with the usual God Mode multiplier). Each target is lifted for 10 seconds, held aboard for 15 seconds with random reactions that do not repeat within an abduction, then lowered for 2 seconds. Multiple abductions run concurrently. Damage is applied every 3 seconds throughout the 27-second sequence (nine small pulses, 4 hearts total with default settings), followed by a three-second per-target cooldown. Turning the beam off does not interrupt existing captures. Teleports do not sweep the space between destinations.

Reality inversion creatures and UFOs emerge through a portal during the first six seconds of their configured duration and return through one during the last six seconds. Their movement and combat pause during transit; the active panel shows Arriving, Active, or Departing. Repeated manual triggers create separate inversions so existing ones can finish their departure.

Player Homes stay unlocked for owners and visitors. Each commercial store has a randomly assigned, stable daily 12-hour opening period based on server time, including overnight hours. Hover over a store building or door to see its hours and open/closed status. Stores stop trading at closing time; customers already inside can still leave. Dungeon locks retain their separate refresh schedule.


The mini map includes **Center on player**, **Inventory**, and **Chat** controls. Inventory and Chat open movable in-game windows with a close box and Escape support. Inventory uses compact equipment tiles and weapon/ammo rows. Player information appears in **Stats** and in the mini map’s **Location** details; God Mode, Hide fog, and Server config live under **Travel**. **Quests** appears only while a quest is active or ready to turn in.

Drag a docked panel by its title bar and drop at the highlighted insertion line to change its sidebar order. The order is remembered across refreshes. Drag near the top or bottom of the sidebar to scroll while arranging panels; dragging outside the sidebar still creates a floating window.

Hover over mini-map markers to see their straight-line distance from your player, updated as the map moves. Indoors, distances are measured from the outside position shown by the mini map and labeled accordingly.

Travel modes use compact illustrated buttons. Hover for the mode name, description, and any current restriction; the selected mode has a gold border and checkmark.

Quest conversations open a centered window with both characters, a varied player question, the giver's details, the exact cash/item reward, and **Accept / Decline**. Offers do not enter the quest log until accepted. Ordinary quests allow at least 45 minutes plus extra travel time; existing untimed quests receive a fresh allowance. Every active quest shows its countdown and next-stage distance/bearing, with yellow minimap objectives (distant objectives stay at the map edge). Completion awards random ammo, crafting supplies, and consumables; rewards that cannot fit are placed beside the player for one hour.

Nearby reality inversions automatically become survival quests: survive the event or defeat all its creatures, with a single quest for a raptor pack. Death fails the survival quest. Manual configuration triggers place their portals within 50 meters of the requesting player's outdoor location, or report that no safe nearby location exists.

The game maintains at least an 8 km/h breeze, even when live weather is calm or unavailable. Idle rafts drift at 0.15–0.6 m/s downwind while staying on water. Each map block receives one yellow wind flag, beside a house entrance or road when available. Closed water bodies of at least 900 square meters receive visible swimming fish and a lake monster, with movement confined to water. Creature selection follows the rendered body, including dinosaur heads and tails. In UFO mode, a dedicated Probulator ON/OFF button appears immediately beneath Travel mode.

Server Config → Reality rebuilding shows on-demand disk usage, saved/active map block counts, starting coordinates, block size, seed, and live world counts. Both preserve accounts, characters, inventories, Home ownership, and purchased maps. Maintenance information and rebuild commands require God Mode.

Ammo, miscellaneous, other, and quest item stacks have no backpack slot limit. Weapon slots and carrying weight still apply.

Crowded clicks show an Actions chooser grouped by every nearby target, including treasure, characters, buildings/doors, bus stops, vehicles, and Home furniture. ## Gardens, farms, and water fixtures

Newly generated map blocks may give up to 5% of residential houses a backyard garden, behind the wall opposite the door. Up to 1% may instead be farms with ten different crop gardens, provided there are no other homes within one-third mile (536.448 meters). Farm generation requires that the entire isolation circle is inside the imported block, so it never guesses about unseen neighboring homes. Existing saved blocks stay unchanged. All plots, including their signs, require a clear grass footprint and clearance from buildings, roads, sidewalks, driveways, water, vegetation, fences, and other objects. Placement is conservative around irregular geometry.

Click a garden for **Harvest** or **Attack garden**. Harvesting gives 1–10 produce and 0–5 matching seeds; Perception, Luck, and Opportunistic improve the odds of larger yields within those limits. Harvests are shared across all players: the same garden stays empty for 12 real hours and says “Check again tomorrow.” Cooldowns persist across restarts. Gardens have 20 health; players can attack them, and nearby hostile NPCs/event enemies can damage them. Destroyed gardens leave rubble for five minutes, then permanently disappear, including after reloads.

Within 40 meters of your own Home, Actions offers **Build garden**. Crafting level 5 is required even in God Mode. The dialog lists each crop's resources and the server-calculated success chance. Each attempt consumes 50 matching seeds, 20 wood, and 5 fertilizer, using Home storage before the backpack. Invalid locations and cancelled previews spend nothing. A valid attempt uses its materials even if construction fails. Choose a location on clear grass; the entire 4 × 3 meter footprint must fit inside the Home range ring. Placement zooms out around Home and restores the previous view afterward.

Garden construction starts at 25% at crafting level 5 with default stats, gains 1.5 percentage points per additional crafting level, and benefits from Intelligence and Luck, up to 95%. **Gardening for dumb shits** permanently adds five percentage points once per character; additional copies do not stack or get consumed. Seeds, fertilizer, wood, and the book appear in loose world supplies and treasure chests. Gardens also yield matching seeds.

Every Home receives a built-in **Kitchen sink** when its furniture loads. Within four meters, the owner can drink directly for purified-water benefits without using supplies, or fill one empty glass bottle/jar from their backpack. A bottle provides the usual purified-water benefits (2 health, 10 water, and a 10% parasite-cure chance); a jar provides five times those benefits (10 health, 50 water, and a 50% cure chance), subject to stat caps. Consuming either returns the corresponding empty container. Filling is deterministic and does not require a crafting level or other ingredients.

Up to 5% of houses in newly generated blocks receive a permanent faucet and garden hose near the front door, clear of the door, driveway, and other objects. Within four meters, Actions offers **Drink from garden hose**. Each drink has a 75% chance of dirty water that always causes parasites and triggers one of thirteen disgusted player remarks. Clean hose water provides purified-water benefits. Hoses cannot be harvested or destroyed.
