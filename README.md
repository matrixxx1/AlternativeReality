# AlternativeReality

A renderer-neutral, self-hosted multiplayer world derived from real geography. One authoritative reality server drives every client: the current browser-based top-down client and, later, a browser-based WebGL 3D client.

The playable vertical slice imports OpenStreetMap geography around downtown Vancouver, Washington as reference data; it never displays a real map. New 2 km geographic cells generate and cache locally as the camera or player explores beyond the loaded area. It builds a stylized angled tile world with roads, sidewalks, textured terrain, complete buildings, vegetation, wildlife, NPCs, vehicles, weather, dungeons, private bases, and players. The authoritative server owns accounts, inventory, movement, combat, trade, health, hydration, stamina, hourly weather, multiplayer synchronization, and SQLite persistence. Normal object modification remains disabled during this exploration milestone.

## Chosen stack

- **Server and canonical model:** C# / .NET 8 and ASP.NET Core. It is cross-platform, fast, easy to debug and publish as a native service, and exposes a renderer-neutral protocol.
- **Browser clients:** dependency-free HTML Canvas and JavaScript for 2D now, with WebGL through an open-source library such as Babylon.js for the later 3D view. Browsers are not limited to tile graphics; the current client already renders projected vector roads and footprints.
- **Shared contract:** canonical C# records define server state, while the versioned JSON protocol is the client boundary. TypeScript definitions can be generated from that contract as the browser client grows.
- **Networking:** JSON over WebSockets for the prototype. Messages describe logical actions and entities. Binary serialization can be added after profiling without changing simulation semantics.
- **Persistence:** SQLite in WAL mode. Only characters and reality deltas are saved; untouched geographic features regenerate from cache and seed.
- **Geography:** cached OpenStreetMap/Overpass plus a cached SRTM90m elevation grid through OpenTopoData, behind provider interfaces.

See [Architecture](docs/ARCHITECTURE.md), [Protocol](docs/PROTOCOL.md), and [database schema](docs/DATABASE.md) for the concrete design.

## Run locally

Requires the .NET 8 SDK. The first run needs internet access to populate the geographic cache; subsequent runs use the cache.

```powershell
dotnet run --project src/AlternateEarth.Server
```

Open [http://localhost:5080](http://localhost:5080). On a completely new server, the first-start screen offers browser location and falls back to manually entered latitude/longitude; this chooses the geography for the reality and is saved locally under `data/`. It is separate from player positioning. A first-time browser then asks for a unique 3–10 character username and password and stores an opaque server-issued session in an HTTP-only cookie. Returning players use the same credentials on a new device.

For access from other devices on the same network, run `tools/open-lan-port.ps1` once from an Administrator PowerShell. It creates an inbound TCP 5080 rule restricted to `LocalSubnet`. Other devices can then open `http://<server-lan-ip>:5080`.

- Move with WASD or the arrow keys.
- Left-click anywhere in the world to walk toward that location. Left-clicking the visible door instead reliably opens its action box with **Enter building** (or **Enter Home** for your base), God Mode **Teleport here**, and a proximity/wallet-aware **Purchase as base** action.
- Use WASD or an arrow key to take direct control and cancel click-to-walk.
- Left-drag or right-drag to pan the camera. A stationary left click still walks toward the clicked location, while a stationary right-click or fast double-click opens the action window.
- Use the mouse wheel to zoom.
- Choose Walk, Run, Skateboard, Bike, Dirt bike, Motorcycle, or Raft. Equipment must be bought before use; God Mode bypasses ownership checks. Running drains stamina, dehydration halves speed, skateboards fail off paved surfaces, bikes retain most of their speed off-road, and rafts make deep water safe.
- Dirt bikes cost $3,000–$5,000 and reach 40 mph; motorcycles reach 90 mph and currently cost $5,000–$10,000. Their separate 2- and 4-gallon tanks consume fuel by actual distance at representative 50 and 45 mpg. Merchants sell gallons for $5–$10 at one advertised randomized price. Empty motorized vehicles cannot move until refueled; God Mode bypasses both fuel checks and consumption. Speed-aware arrival caps prevent fast vehicles from overshooting short navigation targets. Bikes, dirt bikes, and motorcycles cannot be used inside dungeons or Home; walk, run, skateboard, and raft remain available there. The close-up client gives bicycles, dirt bikes, and motorcycles distinct rider and vehicle animations.
- God Mode supplies a 5× movement multiplier, full water/stamina, a $500 wallet floor, health protection/regeneration, equipment access, whole-reality rebuilding, and teleporting. Merchant offers and buildings retain their normal displayed prices, but God Mode can purchase them regardless of wallet balance without deducting any funds. It also exposes a client-side **Hide fog** checkbox. Teleports into unloaded blocks visibly queue geographic generation and complete at the nearest safe walkable point only after that block is ready. The compass button asks the browser for location only when clicked. Browser GPS requires HTTPS or `localhost`; this prototype currently supports GPS locations within the reality's active one-degree projection region.
- God Mode also reveals a persistent server configuration editor for player base speed, base visible range, additive terrain/travel/item speed modifiers, item visibility effects, damage, range, and merchant prices. Every configured inventory row includes **Take 1**, which deposits one item into the account's Home inventory, and **Give 1**, which removes from Home first and then the backpack. Validated changes immediately affect authoritative gameplay and survive restarts. Dynamic characters and treasure are hidden beyond visible range while geographic scenery remains visible throughout the viewport.
- Flashlights, lanterns, and lasers occupy the paper doll's mutually exclusive **Offhand** slot: equipping one turns it on and unequipping it turns it off. A flashlight casts a facing cone, a lantern lights a circle, and the laser draws a straight beam to the first solid object. Each requires its purchased item unless God Mode is active; randomized merchants price lasers from $200–$400.
- Magic hiking shoes are randomized merchant gear priced from $100–$400. Equipping them doubles walking and running speed, halves running stamina drain, and removes the normal mud, grass, and shallow-water speed penalties. God Mode can equip them without ownership.
- Magic running shoes are randomized merchant gear priced from $100–$400. Equipping them triples walking and running speed and halves running stamina drain except on roads and sidewalks. Running and hiking shoes are mutually exclusive, so their bonuses cannot stack.
- The inventory includes a paper-doll equipment view beside a tabbed backpack for **Weapons**, **Quest items**, and **Other** items. The backpack holds three distinct weapon stacks, three distinct quest-item stacks, and six distinct other-item stacks; a stack uses one slot regardless of quantity, while weighted units contribute to the load. The virtual fist is always available and consumes neither a slot nor weight. The backpack has an authoritative 50-pound maximum and progressively slows normal movement by one percent per carried pound, up to a 50% penalty; God Mode ignores that speed penalty. Bikes, inflatable rafts, and motorcycles currently add no player-carried weight, while dirt bikes and motorcycles remain parked assets rather than backpack cargo. Inventory stacks have a **Drop 1** action that creates server-authoritative collectible ground loot; dropping an equipped or active item automatically selects a valid fallback. Weapons, hats, shirts/jackets, pants/shorts, shoes, and offhand lights can be equipped from the backpack or dragged onto their figure slot; clicking a slot unequips it.
- Left-click an NPC or another player to attack with the equipped weapon. Fists deal ¼ heart, rocks deal 1, knives and slingshots deal 2, crossbows deal 3, swords and pistols deal 5, and rifles deal 7. Swords reach slightly farther than fists and knives. Ranged accuracy decreases with distance, melee swings and projectiles are animated, ammunition is consumed outside God Mode, and an empty weapon automatically falls back through lower-power usable weapons to fists.
- Two faint world-space rings surround the player: a 6-meter interaction guide and a second ring matching the equipped weapon's authoritative range. The weapon ring disappears while no weapon is equipped.
- Merchants may sell $20–$40 knives, $300–$500 swords, slingshots, $300–$500 crossbows, 5¢–$5 arrows, $1,000–$3,000 pistols, $3,000–$6,000 rifles, and ammunition at their actual randomized price. Right-click is reserved for contextual actions such as trading, purchasing a base, and God Mode teleporting.
- Quest-giver NPCs offer deterministic item-recovery, animal-hunt, package-delivery, missing-pet, and sword-chopping quests. Specific targets are marked and described with direction/distance clues; missing pets can be captured, and rewards substantially exceed requested item values.
- Swords cut trees and bushes for wood or kindling. Most roadside buildings receive generated mailboxes, roads receive collectible litter and newspapers, and merchants buy carried goods (newspapers are worth exactly 25 cents). Vandalizing mailboxes or parked cars, killing outdoor NPCs, and fighting police raise a persistent wanted level; police arrive after 20 seconds, remain outdoors, and wanted level decays once every five minutes.
- Hardware merchants can sell reusable lock-pick sets. Picking a locked exterior door has a server-side 15% success chance; a witnessed attempt is a crime, and a witnessed success has a separate 10% chance to call police.
- Once per UTC day, the server schedules a UFO flight across the loaded outdoor world. Its green beam deals 10 hearts to any player, NPC, or animal directly beneath its route; police and UFOs remain outside buildings.
- Separate daily ten-minute events spawn a portal-arriving T-rex and a roaming great bear. Both pursue any outdoor player, NPC, or animal in sight and deal 10 hearts per attack; the T-rex receives portal arrival/departure visuals.
- Vehicle merchants sell $4,000–$5,000 e-bikes. Their speed and off-road capability sit between bicycles and dirt bikes; a server-persisted one-mile battery range is consumed by actual distance traveled, after which the e-bike disappears and travel returns to walking.
- Building doors lead to procedural dungeons whose floor outline and dimensions follow the source building footprint. In each four-hour cycle, about 90% of ordinary buildings are locked and marked with a red prohibition symbol; the server rejects entry even if a client has stale state. A player's base and buildings flagged `questItem=true` are always unlocked. Most fresh dungeons have one level; some randomly have 2–10. Multi-level dungeons use one vertically aligned stair location: floor 1 offers down, middle floors offer up and down, and the deepest floor offers up plus a **Leave dungeon** doorway. Floor 1 also retains its exit to the map. Dungeons include fog of war, enemies, chests, and treasure and are discarded on exit. Each account receives a permanent base assignment whose interior is always labeled **Home**, shown only to its owner with a large world-anchored roof flag and compass. Another building starts at $350,000 and increases with size; God Mode still displays that normal price but bypasses affordability and does not deduct funds. The server continues to validate proximity and ownership. Home contains a fireplace and furniture; using the bed restores health, water, stamina, and both five-minute protections. Character management is available through the wardrobe inside Home.
- Home floor dimensions follow the purchased building's approximate footprint. Larger interiors are divided into connected rooms whose interior walls always have door openings. Furniture stores are recognized from OpenStreetMap where available and carry a rotating catalog of beds, dressers, wardrobes, seating, tables, lighting, rugs, storage, decor, and other furnishings at realistic randomized prices. Listings and inventories include item artwork; sensible furniture variants preserve their color, material, and pattern.
- Commercial stores cannot be assigned or purchased as player Homes. Entering one creates a safe, fully revealed shop interior containing only its merchant and store employees—not dungeon dwellers, enemies, or treasure. Seller inventories, quantities, and randomized prices rotate every four hours. With no weapon equipped, left-clicking a merchant walks into trading range and opens the store; contextual **Trade** does the same from any distance.
- Purchased furniture is automatically placed in an open Home location when one exists. Overflow goes to **Home storage**, which is visible only inside the owner's Home. Every Home also receives a persistent storage chest with unlimited item capacity. Its transfer controls accept partial stacks of weapons, ammunition, quest items, and ordinary carried items; withdrawals are checked against backpack slots and the 50-pound limit. Click placed furniture for item actions: drag to move, rotate 90 degrees, return it to storage, or open the item chest. Beds offer **Take a nap** and wardrobes open character management. Furniture placement, variants, rotation, and both storage inventories persist in SQLite.
- Use the bottom chat box and **Say** button to speak. Nearby visible clients see a ten-second speech bubble over the character; **Show chat** opens a client-local history of the last ten messages said or seen, with username and time.
- Wildlife and human NPCs use the same speech system. Birds squeak or call, cats meow, dogs bark, and residents tell random jokes on independently randomized schedules ranging from two to thirty minutes.

Paved surfaces use a representative 3.5 mph walking speed, forest uses 2 mph, sand uses 1 mph, and mud, grass, and shallow water have their own canonical rates. Click-to-walk asks the server for a route around solid geometry. Deep water is deliberately excluded from routes; manually entering it drowns and resets the character to a safe starting point.

A brand-new account receives a base assignment but begins at a deterministic random safe outdoor point in the server's world—not at its browser GPS location. Reconnects resume the character's persisted outdoor or available interior location; deaths return to the account's current base. The God Mode **Reset & rebuild reality** action clears generated regions, dungeons, chests, dungeon exploration, relationships, and player-created world deltas across the server before regenerating the world; accounts, characters, inventories, current base ownership, and purchased block maps remain.

The browser starts at a close 26-pixels-per-meter view and can zoom further in to 40 pixels per meter. **Center on player** and interior transitions restore that maximum zoom. Zooming out still activates the lighter rendering levels for performance.

Every persistent HUD window has a `−`/`+` control. Collapsed state is remembered in that browser, including the inventory's existing Hide/Show setting.

Real street names, airports, state borders/names, addresses, shops, gas stations, furniture stores, and parcel lines are imported when OpenStreetMap supplies reliable tags. Hovering a building shows its available address. Parcel boundaries become stylized fences with open gates on at least two sides. Geographic food, gas, furniture, weapon, vehicle, clothing, hardware, sporting-goods, and convenience businesses create color-coded storefronts and roof flags naming what they sell. Hardware and sporting-goods merchants carry randomized weapons/bikes; vehicle dealers carry dirt bikes and motorcycles. Moving any edge of the viewport into a new geographic cell starts loading before the player enters it, shades that exact area, and draws a pulsing boundary with repeated **LOADING MAP** signs and elapsed time. A persistent task banner distinguishes loading, generation, routing, and client rendering work. New terrain arrives under near-opaque fog with faint block lines; merchants sell a $1–$1,000 map that permanently reveals the current block for that player and is never offered there again. Snapshots identify exact loaded cells, so diagonal exploration cannot clear fog over an ungenerated hole inside the world's aggregate bounds. Generated maps and raw geographic caches stay local to each reality server under `data/`.

Buildings cost at least $350,000, with the authoritative normal price growing exponentially from the footprint's estimated square footage. That normal price is always displayed. God Mode bypasses affordability and wallet deduction without changing the quoted price.

The reality configuration—including center, size, name, seed, and player limit—is in `src/AlternateEarth.Server/appsettings.json`. Runtime state is written under `data/` and is intentionally not committed.

## Verify

```powershell
dotnet test AlternateEarth.sln
node tools/smoke-test.mjs
```

The smoke test creates two authenticated accounts, confirms base assignment, opens two real WebSocket clients, synchronizes movement and chat, verifies God Mode resources and pathfinding, and confirms that exploration-only object placement remains blocked.

## Geographic attribution

Map features are © OpenStreetMap contributors and used under the [Open Database License](https://www.openstreetmap.org/copyright). Elevation is requested from an OpenTopoData SRTM90m endpoint and cached locally.

Current temperature, precipitation, and conditions are supplied by [Open-Meteo](https://open-meteo.com/) and refreshed by the reality server hourly. The client derives sunlight from sunrise/sunset, shows the current moon phase, brightens full-moon nights, and gives the player a small local light in darkness.

The server also tracks a persistent 0–100 body-heat meter. Standing still below 50 °F loses warmth; suitable movement and insulated hats, shirts, sweaters, jackets, and warming pants reduce that loss. Moving above 80 °F raises body heat; cooling hats, shirts, and shorts reduce heat gain and improve cooling. Reaching zero warmth slowly removes hearts, while overheating rapidly drains stamina. Indoor areas recover toward a comfortable temperature, and God Mode remains climate-protected.
